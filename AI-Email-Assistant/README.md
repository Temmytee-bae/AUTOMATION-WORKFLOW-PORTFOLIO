AI Email Assistant
Project Overview
An AI-powered email management workflow built with n8n to classify incoming emails, assess their priority and prepare response drafts.

Key Features
- Automatically detects incoming Gmail messages.
- Uses AI to classify emails into categories:
  Sales, Support, Billing, Partnerships, Jobs and Others.
- Assigns priority levels: High, Medium and Low.
- Flags emails requiring human review.
- Routes emails based on their classification.
- Creates response drafts for human review before sending.

Tools & Technologies
- n8n
- Gmail
- Google Gemini
- AI Agent
- Switch Node

Workflow
Incoming Email → AI Classification → Priority Assessment → Routing → Draft Creation

Important Note
The workflow creates email drafts rather than automatically sending responses, keeping a human in control of outgoing communication.
